# Hamada LIVE Web V28

نسخة ويب مصممة لتعمل بنفس **فكرة** أنظمة TikTok Overlay السحابية: محرك اتصال بالخلفية + لوحة تحكم بالمتصفح + رابط Overlay مستقل للبث.

## ما الموجود

- **التركيبات:** آخر متابع وآخر مكبس أفقيًا، صورة واسم وتأثيرات حول الصورة، بدون بطاقة خلفية.
- **التصنيف:** ترتيب المكبسين من 1 إلى 5 مع تاج للمركز الأول وتأثير على الاسم.
- **الإجراءات:** أليرت دخول يوزرات تحددها أنت + أليرت عند وصول المتابع إلى حد معين من التكبيسات.
- **القارئ الصوتي:** يسمح للمشرفين والمتابعين أو يوزرات محددة.
- **الموسيقى:** مكتبة ملفات صوتية وأوامر `!تشغيل اسم الأغنية` و`!صوت5` و`!تخطي` و`!ايقاف مؤقت` و`!تشغيل` و`!ايقاف`.

## التشغيل المحلي للتجربة

شغّل `START_LOCAL.bat` ثم افتح:

- لوحة التحكم: `http://127.0.0.1:8799/`
- Overlay: `http://127.0.0.1:8799/overlay`

يجب أن يكون Node.js 20 أو أحدث مثبتًا.

## التشغيل السحابي الحقيقي

المشروع مجهز لـ **Cloudflare Containers**. بعد النشر تحصل على رابط HTTPS واحد، مثل:

- لوحة التحكم: `https://your-domain/`
- Overlay: `https://your-domain/overlay`

Cloudflare Containers تحتاج Workers Paid (الحد الأدنى حاليًا 5$ شهريًا)، وتسمح بتشغيل تطبيق Node/WebSocket كامل داخل Container.

### النشر

1. Docker Desktop يجب أن يكون شغالًا.
2. شغّل `DEPLOY_CLOUDFLARE.bat`.
3. سجل دخول Cloudflare عندما يفتح المتصفح.
4. بعد النشر، استخدم رابط `workers.dev` أو اربط دومينك.

## Euler Stream اختياري

المحرك يستخدم `tiktok-live-connector`. يمكنه محاولة الاتصال باسم المستخدم مباشرة. إذا احتجت ثباتًا أعلى في توقيع اتصالات TikTok، ضع Secret باسم `EULER_API_KEY` في Cloudflare. لا يتم وضع المفتاح داخل صفحة المتصفح.

## ملاحظة التخزين السحابي

ملفات Cloudflare Container المحلية مؤقتة عند إعادة إنشاء الـContainer. النسخة الحالية مناسبة للتجربة والنشر الأول. للنسخة الإنتاجية النهائية سنربط مكتبة الموسيقى والإعدادات بـR2 حتى تبقى دائمًا بعد أي إعادة تشغيل.
